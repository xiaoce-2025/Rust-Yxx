# 回放链接插件 1.7

将 `pku-replay-link.user.js` 的全部内容替换到原油猴脚本中，保存后刷新教学网回放页面。请先确保该回放能够正常播放，再点击「复制下载地址（自动带密钥）」。

插件会读取播放列表中的实际密钥 URI，使用当前浏览器登录状态取得 16 字节密钥，以 `hex:` 格式编码后放进链接的 `enc_key` 参数。例如：

```text
https://resourcese.pku.edu.cn/.../playlist.m3u8?enc_key=hex%3A000102030405060708090a0b0c0d0e0f
```

链接已有查询参数时自动使用 `&enc_key=`，其余参数保持原始编码。支持主播放列表、相对密钥路径以及二进制密钥；获取失败时显示原因，不复制缺少密钥的加密链接。

本项目的「回放中转与下载」「课堂笔记生成」页面已同步支持此参数，粘贴即可提交。页面将参数转换为 `manual_key`，实际下载 URL 会移除 `enc_key`。旧的无参数链接仍保留手动密钥流程。更新服务端后这些页面改动才会生效。

此参数用于本项目导入，不是通用播放器的密钥标准。本次通过模拟请求做了自动化测试，尚未在真实教学网登录会话中验证；若出现获取失败，请提供页面显示的错误文字。

跨域请求与二进制响应使用 [Tampermonkey 官方 GM_xmlhttpRequest API](https://www.tampermonkey.net/documentation.php?q=GM_xmlhttpRequest)。
