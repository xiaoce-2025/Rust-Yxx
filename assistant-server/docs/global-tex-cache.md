# 跨账号全局 TeX 缓存

本次实现设计 V1.3 中的缓存机制和后台查看能力。用户中心独立的任务进度页面不属于本次改动；现有课节轮询和任务列表继续工作。

## 执行规则

- 仅以 `SHA256(PreparedMedia.url 原始 UTF-8 字节)` 作为身份，不包含用户、课程、日期、模型或提示词。
- 提交阶段只保存任务与课程快照，不读缓存、不合并任务、不提前完成任务。
- Worker 领取后验证全局 TeX 的 UTF-8、非空内容及 SHA-256。缺失或损坏按未命中处理。
- 普通任务命中即复制；重新生成任务在用户 `initial_tex_hash` 非空且与全局内容哈希不同时复用，否则完整生成。手工保存和课程刷新保留初始哈希。
- 同 URL 的任务在队列中互斥，等待任务保留原始序号；不同 URL 可使用空闲 Worker。独占资格直到用户结果安装和完成通知结束才释放。
- 生成流水线完成 PDF 校验后发布全局 TeX，字节复制到当前用户；不会遍历或覆盖其他账号的笔记。课节替换沿用 `.removed-notes` 备份和课节安装恢复事务。

## 共享边界

跨账号共享只对现有课程提交流程取得的课堂回放启用，包括批量课节和课程重新生成。保留该流程原有用户与课节检查、教学网/App 凭据准备流程。

任意直接 URL 提交缺乏可靠的课堂回放共享授权标识，因此默认不进入全局缓存，仍正常排队和生成独立 TeX。不能通过客户端传入 `share_cache` 开启共享。旧任务的该字段也默认关闭。

## 存储及自动迁移

启动 `FileStore` 时执行可重复运行的 SQLite 迁移，无需手工 SQL：

- `global_tex_cache`：每个 URL 一条当前记录，保留内容哈希、revision、源任务、时间、命中计数；预留 `video_duration_seconds`。旧表缺列时通过 `PRAGMA table_info` 检查后补列。
- `global_cache_course_observations`：按任务 ID 去重的课程、日期及课节快照，无缓存外键；缓存尚不存在时也可记录。
- `global_tex_publications`：发布恢复日志，临时保留元数据与待发布的 TeX 字节。文件 fsync、同目录原子替换完成后，在同一 SQLite 事务中更新索引并删除日志。启动及下一次读取会重放未完成发布。
- `PkuVideoJob` 新字段均有 serde 默认值；旧课节缺少 `initial_tex_hash` 时保持 None，不从用户现有文件反推。

文件位于 FileStore 数据目录下的 `global_tex_cache/<哈希前两位>/<完整哈希>.tex`。生成的独立结果位于 `user_notes/<user-id>/<job-id>.tex`；课节通过原有安装流程写入 `course_data`，安装成功并持久化完成状态后删除私有交付快照。只使用字节复制，不使用硬链接。

成功后清理任务工作区中的视频、音频、转写及 PDF。PDF 下载在临时目录按需编译并清理。失败的生成不改变已安装笔记或旧缓存。

## 故障恢复

编译成功的用户结果在发布缓存前先形成私有持久副本，并保存结果元数据。发布或安装中断时，启动先补完尚未完成的缓存发布，再重试该副本的安装，不重新调用模型；后续任务已推进的全局版本不会被旧发布反向覆盖。课节索引中的初始哈希随原有课节文件事务提交；独立任务的初始哈希保存在用户专属索引中。

没有完整生成结果的 Pending/Running 任务在重启后明确标记中断失败，填写结束时间，允许用户重新提交。当前实现不自动重新执行下载/模型任务。若同一目标已有更新的成功任务，不恢复旧任务覆盖新笔记。

生产部署继续依赖现有 `assistant.lock` 单实例锁。多实例共用数据目录需要另行实现跨实例 URL 租约，不能移除实例锁后直接并行部署。

## 接口变化

- `POST /api/pkuvideofullclass/courses/:course/videos/:lesson/process` 支持可选 `regenerate`，默认 false；true 时同样检查管理员功能开关。
- 原 `/reprocess` 直接创建重新生成任务，不再先删除原笔记。页面确认提示覆盖个人编辑，沿用提交、密钥补充及任务轮询流程。
- 单视频 submit/submit-web 支持 `regenerate`；原逐步骤重执行接口改为提交新的完整重新生成队列任务，返回新的 job_id，不再绕开 Worker 执行。
- `GET /api/pkuvideo/jobs` 和详情返回安全投影，隐藏源 URL、密钥、本地路径和内部错误文本。保留页面使用的字段，`pdf_path` 为下载接口地址。
- 新增 `GET /api/pkuvideo/jobs/:id/tex`，仅当前用户可读取自己的成功任务；PDF 使用用户副本按需编译。
- 新增管理员鉴权接口 `/api/admin/tex-cache?q=&page=`、`/:url_key`、`/:url_key/tex`。后台新增全局 TeX 缓存导航、分页搜索、哈希/版本/命中次数、关联课程详情和 TeX 预览；任务列表补充课程快照、重新生成标记与来源。源 URL 不进入管理列表。

## 验证

自动测试覆盖缓存决策矩阵、两账号独立副本、编辑后重新生成、旧版领取新版、生成失败保留旧结果、旧索引缺基准、损坏缓存、发布日志重启恢复、安装中断恢复、同 URL 排队互斥及 FIFO/优先级、后台鉴权与用户 DTO 脱敏。

运行 `cargo test -- --test-threads=1`。HTTP 集成测试需要允许本机回环连接；真实教学网/App、下载、ASR、LLM 和 XeLaTeX 完整链路仍需部署环境凭据与工具做实际验收，自动化缓存测试用可控生成器代替外部服务。
