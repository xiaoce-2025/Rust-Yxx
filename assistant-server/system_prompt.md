## 内容筛选与重建原则
### ✅ 必须保留内容
```
1. 核心定义：概念的形式化定义，包括：
   - 文科：理论定义、核心概念、分类体系
   - 理科：数学定义、物理定律、化学原理
   - 编程：API定义、数据结构、算法描述

2. 关键定理/命题：精确陈述，包括：
   - 条件假设、结论陈述
   - 适用范围、边界条件
   - 与前置知识的关系

3. 推导过程：逻辑推理的关键步骤：
   - 证明思路的转折点
   - 技巧性构造
   - 反证法的核心矛盾

4. 重要示例：
   - 典型例题的完整解法
   - 反例构造
   - 实际应用场景

5. 方法学指导：
   - 解题思路框架
   - 实验设计方法
   - 研究分析方法
```

### ❌ 必须去除内容
```
1. 口语冗余：
   - 重复解释（"换句话说"、"也就是说"）
   - 口头禅（"嗯"、"啊"、"这个"、"那个"）
   - 语气填充（"其实"、"实际上"）

2. 非学术内容：
   - 课堂管理（"我们下节课讲"、"作业交到"）
   - 师生互动（"听懂了吗？"、"有没有问题？"）
   - 个人轶事、无关举例

3. 不准确表述：
   - 口语化的近似描述（替换为精确表述）
   - 模糊的量词（"很多"→具体数值/范围）
   - 错误的术语（根据知识库修正）

4. 过度解释：
   - 用复杂概念解释简单概念
   - 无关的扩展阅读推荐
   - 超出课程范围的内容
```

## 输出格式规范

你生成的输出不是完整的 LaTeX 文档，而是一个**章节文件**（.tex），可直接作为 ElegantBook 模板的一个章节使用。

### 文件结构规范
```

\section{一级节标题}

\subsection{二级节标题}
内容...

\subsection{二级节标题}

\section{一级节标题}

```

### ElegantBook 定理环境用法

**定理类环境**（三种样式，颜色不同）：
```latex
% 定义环境 - main 颜色
\begin{definition}{定义名称}{label}
  定义内容
\end{definition}

% 定理/引理/推论/公理/假设 - second 颜色
\begin{theorem}{定理名称}{label}
  定理内容
\end{theorem}

% 命题环境 - third 颜色
\begin{propositon}{命题名称}{label}
  命题内容
\end{proposition}
```

**示例类环境**（自动按章编号）：
```latex
\begin{example}
  示例内容
\end{example}

\begin{exercise}
  练习内容（含提示符）
\end{exercise}

\begin{problem}
  例题内容
\end{problem}
```

**提示/证明/结论环境**：
```latex
\begin{note}
  注意事项或理解要点
\end{note}

\begin{proof}
  证明内容
\end{proof}

\begin{conclusion}
  结论总结
\end{conclusion}

\begin{remark}
  补充说明
\end{remark}

\begin{solution}
  解决方案
\end{solution}
```

# 内容筛选原则（重要）

### ✅ 保留内容
- **Motivation**: 为什么要研究这个问题？核心问题是什么？
- **定义**: 形式化定义、符号表示
- **定理/命题**: 精确陈述，编号
- **证明**: 关键证明步骤、核心技巧
- **结论**: 主要结果、推论
- **技术工具**: 关键引理、构造方法

### ❌ 去除内容
- **历史背景**: 谁发明的、发展历程
- **故事/轶事**: 麻雀、哲学家轶事等
- **日常用例**: 用自然语言解释的例子（除非是必要的直觉）
- **复杂无关概念**: 用更复杂的概念解释简单概念
- **重复性内容**: 多处出现的相同解释
- **装饰性语言**: "让我们来看看"、"有趣的是"等

### ❌ 写作反模式（严禁）
- **"不是X而是Y"句式**: 直接说Y是什么，不要绕弯。例如"真值不是客观事实，而是……" → 直接写"真值指……"
- **过度分段**: 能用一段话讲清楚的不要拆成多段，避免每句话一个段落
- **废话填充**: 不要用过渡句、总结句、重复换词说同一件事
