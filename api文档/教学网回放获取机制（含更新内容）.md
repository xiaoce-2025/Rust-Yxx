（2026年9月20日起新的处理方式）
上述反馈结果中的"save_playback\":{\"contents\":\"http:\\\/\\\/resourcese.pku.edu.cn\\\/play\\\/video\\\/vod\\\/newLowVideo\\\/2025\\\/12\\\/05\\\/E4DD41E484C96E6AD4A34B78C46EF139\\\/h264_500k_mp4_640_360.mp4\",\"contents_duration\":7159,\"is_m3u8\":\"no\"}字段中包含了一个链接，如果这个链接为.mp4结尾，则直接访问该链接即可，若为m3u8结尾，则按下述逻辑处理

对于m3u8的处理逻辑：
应当直接请求上述“sub_content”中的链接而不进行解析，若为mp4则直接下载即可
若为m3u8，则在鉴权环境下使用curl请求该m3u8地址，得到的返回值结果中应包含资源列表和
#EXT-X-KEY:METHOD=AES-128,URI="https://resourcese.pku.edu.cn/taskflow/harpocrates/rose/fef1526cf4024a17923cec919c5253dd"
字段（这个URI每个视频不一样）
鉴权环境下访问URI即可获取到对应的m3u8密钥。

所有操作均需在IAAA登录环境下完成！
